# Todo App

This project is a App used to track ones todos. I built it to challenge my frontend development skills by creating a project with typescript for functionality.

This project focuses on real interactive fuctionality.

## Built With

* HTML
* CSS
* Typescript

## What I Learned

* Improved my ability to add functionality to a website
* Strengthened my thinking as a upcoming software engineer.
* Gained more confidence using typescript

## Future Improvements

* Use a real database/backend to store the todos.
* Improve accessibility.

## Running the Project

- `git clone https://github.com/ayabiodun/Todo-App.git`
- `cd Todo-App`
- `npm install`
- Then open the `index.html` in your preferred website.
